# NetMusic Radio Addon
A radio station search and playback addon for the `netmusic:big_megaphone` in [NetMusic](https://modrinth.com/mod/net-music). Provides a searchable radio browser with favorites, online/local search, and more Shoutcast/Icecast stream support.

本mod为[NetMusic](https://modrinth.com/mod/net-music)的大喇叭做出非m3u8流广播的支持，并添加了一个广播搜索功能以及收藏夹功能

Click the "Select Preset Station" button to go to the search browser

点击“选择预设电台”按钮即可进入搜索页面
